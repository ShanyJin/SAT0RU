基于 [reinesana/SAT0RU](https://github.com/reinesana/SAT0RU) 的私人合并版：把仓库里 10 个未合并 PR 里有价值的部分全部手工并入了一个 `index.html`，再按主人要求删到只剩本作技法；PR #7 的开场动画已移植进主场景——無量空処手势定格 3 秒自动播放。改版作者：**闪耀金金 / ShanyJin** · [shany.cc](https://shany.cc) · [shanyaojinjin/SAT0RU](https://github.com/shanyaojinjin/SAT0RU)。

## 相比原版改了什么

### 1. 识别引擎重写（解决「手势不灵」的根因）

原版是单帧硬判断：每一帧按 y 坐标猜手指伸没伸，猜错一次特效就跳一次。最终版改为 **分数制 + EMA 平滑**（PR #6 的思路，重写实现）：

- 每个手势每帧输出 0~1 分数，EMA 平滑（α=0.20）
- 进入阈值 0.75 / 退出阈值 0.50，防抖
- 切换技法需领先当前技法 0.12 且持续 300ms 以上
- 单帧抖动不再跳变，双手中优先级排定（双 fists > 捏合+平掌 > … > 单手中最高分）

手势规则本身也收紧了（吸收 PR #10）：四指「并拢/张开」按食指-中指指尖距离区分（<0.05 / >0.10），捏合会抑制其他手势，拇指外张、双指夹角都参与判定。阈值集中在 `index.html` 的 `computeHandScores()`，不合手型可直接微调。

### 2. 只保留本作技法（其余上游技法已删）

上游合并版曾有 15 个技法；现在按主人要求全部删除，只留 **苍 / 赫 / 無量空処**（外加茈按钮模式、双手契印与 flick 尾巴）。
`?mode=all`、T 轮换、独立开场页入口、音乐、按键表、纯净模式都已移除；界面、技法名与 About 全部中文化。

### 3. 五条悟模式（当前默认）· 启用「苍」「赫」「無量空処」，茈有按钮模式与双手契印

「苍」是**持掌式**：张开手掌对着镜头**保持 2 秒** → **构筑**（手心先聚成小粒子球，随后展开成一大片呼吸浮动、飘散感明显的蓝色粒子状态，直径约 15~25cm，跟着手走）→ **释放**（持续前推 / 合掌 / 手出画面 / 丢失追踪 → 蓝色大爆炸）。构建期间慢速移动、旋转都不会打断；**构筑成型再满 2 秒才播苍的语音**（`audio/blue.mp3`，每次构筑一次；提前释放/取消不播）。**赫**有两种手势：单手食指向上指，或食指+中指并拢、拇指外张（枪形）——红色场的核心红点悬在手指所指方向外约 5~10cm、跟手移动，指住即持续展开、收手退场，两种手势互换不断档；**任一赫手势保持 1 秒会随机播放一段赫的语音**（`audio/he-1|2.mp3`，每次保持播一次）；苍构筑/释放期间赫不触发，赫形态出现的帧也会清零苍的时序检测（快速比枪形不会误触）。**任何术式触发后 2 秒冷却**，防止前甩后手回收时的回摆连锁触发下一个术式。**虚式「茈」**有两种用法：右上角的模式开关（开启后苍/赫暂停，枪形/捏合/拇指内扣蓄势紫色小球，前推或「拇指内扣后快速向外弹开」发射到屏幕正中心爆开，**发射瞬间播 2026 短语音** `audio/purple-2026.mp3`，再点关闭恢复），以及**双手交叉扣合**（十指交扣、食指朝上、拇指内扣）——不需要点按钮，扣住就发动：左侧蓝色粒子球 + 右侧红色粒子球同时变大，向中心靠拢重叠，随后炸成紫色大爆炸；单手同形仍然是無量空処（契印专属语音待踩点接入）。**領域展開「無量空処」**按参考视频：食指+中指并拢/交叉、拇指内扣（拇指外张的枪形仍是赫），展开白环 + 蓝色星云场，保持手势维持、松手退场；**比出满 1 秒播单人版语音**（`audio/void.mp3`）；**定格超过 3 秒**会自动播放旧 PR #7 的开场动画（已去掉标题与「进入」按钮），结尾从流星宇宙换成本作自己的白环粒子场——**环出现后黑幕再保持 10 秒**，随后黑幕淡出、背景透明而环还在，最后环淡出收场（一次保持只播一次，松手再结印可重播）。左侧栏设置里的**「长时间无量空处」**开关打开后，無量空処改成**保持 1 秒**即进入约 34 秒的超长版：31 秒长语音与动画同帧开始，**语音先结束、动画后结束**（`audio/void-long.mp3`）。

**音频库**：左侧栏新增「音频 · Audio」区块，7 条本地语音各一行，点击播放/停止（同一时间只播一条）：苍、赫·一/二、無量空処·单人/长版、茈模式 2026、双手契印（待接入）。全部本地文件，零外网请求。

**引力 / 斥力与待机尘埃**：屏幕常驻一层 1200 颗的灰蓝**环境尘埃**（慢速漂浮，就是「待机粒子」）——苍是吸引：构筑时尘埃螺旋收拢到蓝球四周，绕球旋转、跟着手走，释放瞬间被炸散再漂回；赫是排斥：红球出现时以红点为圆心把尘埃排开成一圈净空，收手后尘埃缓缓漂回。所有形态过渡都用逐粒子阻尼（0.18~0.48s）衔接，不会瞬移。

**技法名**一律用原版：術式順転「蒼」、術式反転「赫」、虚式「茈」、領域展開「無量空処」（顶栏中央状态显示，白色大字）。

### 4. 界面：Win11 石墨 Acrylic + 摄像头合成

页面按 Win11 风格重做（石墨灰黑底、毛玻璃卡片、暖金强调色；规范见 navi `skills/web-design.md`）。摄像头画面全屏铺底并镜像，粒子特效以 `mix-blend-mode: screen` 叠在画面上，术式像是直接在你所在的房间里展开。

顶栏是三段式：**左上角菜单按钮**开合左侧栏；**正中央**用大号白字显示当前技法原名（繁体，如「領域展開『無量空処』」），没有发动任何术式时**不显示任何文字**；**最右侧**是「茈」模式开关和一行提示（点击开启 / 已开启的虚式「茈」枪指模式）。左侧栏是一整块 Windows 11 风格的透明亚克力面板，内部按 **设置 / 音频 / 手势指南 / 关于** 分区：设置区是 Win11 式开关（调试、指南、语音、长时间无量空处，点击即切换，等价于 D/H/V/L）；**音频 · Audio** 区列出 7 条本地语音，一行一条、点击播放/停止；**关于 · About** 写明改版作者、个人网站、改版仓库、原项目、开源依赖和本地化说明。手部骨架只在 **D** 调试模式下绘制。

## 手势表（当前启用苍 / 赫 / 無量空処 + 茈按钮模式与双手契印）

| 手势 | 流程 |
|---|---|
| 单手或双手：张开手掌对着镜头保持 2 秒 | 苍：构筑 → 跟手 → 前推/合掌/丢手释放（尽量单手使用） |
| 构筑成型后再保持 2 秒 | 苍语音：播 `audio/blue.mp3`（每次构筑一次；提前释放/取消不播） |
| 单手食指向上指，其余三指收拢 | 赫：红点悬在手指所指方向外 5~10cm 跟手移动，指住即持续、收手退场；苍构筑/释放期间不触发 |
| 食指+中指并拢、拇指外张（枪形） | 赫：同上（参考视频「赫 1/2/4」的第二种手势，两者可互换不断档） |
| 任一赫手势保持 1 秒 | 赫语音：随机播放 `audio/he-1.mp3` 或 `audio/he-2.mp3`（每次保持一次） |
| 点右上「茈」→ 枪形/捏合/拇指内扣蓄势 → 前推或拇指外弹 | 茈：紫色小球射向屏幕正中心爆开，发射瞬间播 `audio/purple-2026.mp3`；松手取消，释放后 2 秒冷却 |
| 双手交叉扣合（十指交扣、食指朝上、拇指内扣） | 茈·双手契印：左蓝右红两颗粒子球长大 → 向中心靠拢重叠 → 紫色大爆炸；无需点按钮、单手无效；专属语音待踩点接入 |
| 食指+中指并拢/交叉、拇指内扣 | 無量空処：白环 + 蓝色星云；拇指外张的枪形仍是赫，两者靠拇指内扣/外张区分 |
| 無量空処保持 1 秒 | 无量空处语音：播 `audio/void.mp3`（单人版；每次保持一次） |
| 上一条保持定格 >3 秒 | 自动播放开场动画：流星宇宙 → 白环粒子场出现在黑幕上 → 黑幕保持 10 秒 → 黑幕淡出、透明背景上环还在 → 环淡出 → 自动恢复 |
| 设置开「长时间无量空处」→ 無量空処保持 1 秒 | 超长版：约 34 秒动画 + 31 秒语音 `audio/void-long.mp3`，同帧开始、语音先结束动画后结束 |

- **赫**：复用库里原有的食指规则（`handShape().indexUp` + 其余三指收拢）与 `getRed()` 粒子演出；第二种枪形为 `indexUp+middleUp+指距<0.065+拇指外张（`thumbGapRatio`>0.75）+无名小指收拢`。EMA 平滑保证手指姿态过渡不会误触；红色激活期间两种手势切换或短暂丢手（<350ms）由桥接逻辑保持不断档，避免冷却期断触。任一赫形态出现的帧都会把苍的时序清零（`redFormSeen`）——做枪形时「张开→收指→张开」的自然动作不会误武装苍。整个红色场以「指尖（枪形取食指+中指中点）+ 沿指方向约 9×指节长度（≈7cm）」为锚点做阻尼跟随（`redAnchor`/`redFollow`，110ms），收手后退回屏幕中央淡出。构筑或释放苍期间赫被屏蔽（`frameScores.red = 0`），两个术式不会互相打断
- **术式冷却**：任何术式触发（苍释放/赫展开/茈发射/無量空処展开）后 2 秒内不再触发任何术式（`TECH_COOLDOWN_MS`，D 面板 `cooldown` 可见）——解决「赫前甩后手回收时又触发苍」的连锁误触；已激活的赫不受影响，会正常持续

- **苍的构筑**：张开手掌对着镜头**保持 2 秒**（前 3 帧确认张开才开始计时；握拳/收手即清零，按手独立、单手双手都认）后**不立即绽放**——**手心**先聚起小球，约 2 秒内展开成一大片「粒子状态」（直径约 15~25cm，`growMs`）：亮核 + 三条不同倾角的粒子环带（其中一条反向旋转，弧段留空隙）+ 大范围飘散体积雾（±26% 半径浮动），整体还有双频呼吸式胀缩（±16%/+7%）——像被释放出来的游离状态而非实心球，共 4000 颗。整团带阻尼跟手移动（拖动时拖在手掌后、停下再追上），并随**手腕转动**加减旋转。慢速大范围拖动、转动腕子都不打断；双手做也只锚定先完成的那一只手。构筑成型后再满 2 秒播苍语音（`BLUE_SEQ.voiceDelayMs` 与 `BLUE_SEQ.holdMs` 相互独立；提前释放/取消不播）
- **环的收尾**：無量空処开场动画里白环出现后黑幕保持 10 秒，之后黑幕淡出、背景透明而环还在，环再单独淡出；长版把黑幕保持拉长到 24 秒，总长约 33.8 秒，仍然「语音先结束、动画后结束」
- **释放**：持续前推（掌尺寸连续增长 ≥3 个采样、≥110ms、累计 ≥24%、平均增速 ≥1.7/秒；中间任一采样不涨即断链）、**双手合掌**（两掌贴近约 ≤0.13）、手移出画面、追踪丢失超过 1 秒 → 光球瞬间消失，**屏幕中央**绽放蓝色大爆炸；慢速移动、横向挥动、转腕都只跟手，不释放
- **触发锁**：苍释放后演出约 2.5 秒，随后再锁 2 秒；另叠加全局 2 秒冷却（任何术式触发后）——期间任何手势都不触发
- **待机尘埃**：没有术式激活时保留一层轻量环境尘埃（1200 颗，慢漂移）；20k 主粒子场仍然整个隐藏（不占 GPU），构筑时只有光球粒子群 + 被吸过来的尘埃在跑。苍的引力把尘埃吸到蓝球四周旋绕并跟手，赫的斥力在红球周围清出一圈净空——引/斥的就是这层尘埃
- **语音**：全部本地 `<audio>`，首次点击/按键静音预热解锁自动播放；同一时间只播一条（新语音会停掉上一条）；赫/無量空処是「保持 1 秒 → 播一次」，苍是「构筑成型后再过 2 秒 → 播一次」；松手/释放后重比可再触发；左侧音频库可手动播放任意一条
- 构筑另有 30 秒安全上限（防止追踪卡死导致永远挂在构筑态）；手别标签翻转时会按邻近位置重新捕获
- 张开/握拳按「指尖到手腕距离 vs 指节到手腕距离」判定（>1.12 张开、<0.92 握拳），不依赖手掌朝向
- D 调试面板会显示 `fps`、`charge`（含实时手速）、`blueStages`、`bluePulse`、`gestureLock`、`cooldown`——阈值集中在 `CHARGE`、`BLUE_SEQ`、`VOICE_HOLD_MS`、`VOID_CINEMA`、`VOID_CINEMA_LONG`、`TECH_COOLDOWN_MS` 和 `handShape()`

## 运行

- 项目根目录 `/home/lain/sat0ru`，常驻服务 `sat0ru.service`（systemd 用户级，只监听 `127.0.0.1:8787`）：
  ```
  systemctl --user status sat0ru      # 状态
  systemctl --user restart sat0ru     # 改了代码不用重启，刷新页面即可；服务挂了用这个
  ```
  手动起（临时调试）：
  ```
  cd /home/lain/sat0ru && python3 tools/serve.py . 8787
  ```
  打开 `http://127.0.0.1:8787`；外网访问走 SSH 隧道。
- 需要摄像头；浏览器只在 `localhost` / HTTPS 下允许取摄像头
- `tools/serve.py` 已配好 MIME（`.wasm` → `application/wasm`，`.data` / `.tflite` → `application/octet-stream`），换别的静态服务器也要保证这两条
- 全部依赖已本地化在 `vendor/`（MediaPipe Hands、three.js、字体），**零外网请求**

## 已知限制

- MediaPipe Hands 是 2D 关键点 + 逐帧检测，极端光照、逆光、手太远仍会丢手；后续若还灵，升级路径是 MediaPipe Tasks `HandLandmarker`（新模型、世界坐标、时序更稳）
- 粒子用 screen 混合叠在摄像头上：画面极亮（比如对着窗户）时粒子会偏淡，属于预期；降低曝光或调高 bloom 可缓解
- 无摄像头/拒绝授权时 MediaPipe 会弹「Failed to acquire camera」，正常
- 「前甩」用 2D 手速和手掌尺寸增速做代理（没有深度）：逆光或追踪严重抖动时仍可能误判，调 `CHARGE.speedThresh / growthThresh / lostMs` 改灵敏度，`followTauMs / trailScale` 改拖拽跟手手感
- 若构筑粒子群看起来卡顿：按 D 看 `fps`，持续低于 ~30 多半是 GPU 吃紧（核显 / 浏览器退到软件渲染），关掉其他占 GPU 的标签页即可；渲染分辨率已封顶 1.5×DPR，主粒子场在待机/构筑时整个隐藏，待机只剩 1200 颗尘埃当底噪，开销很小
- 「run away」语音识别依赖 Web Speech API，走 Google 在线识别，国内网络可能不通；术式语音和左侧音频库都是本地 MP3，不受影响
- 1 秒语音判定用的是连续手型保持，手抖或短暂丢手（<500ms）会算同一次保持；苍语音在构筑后才计时，提前释放就听不到。想更稳可调 `VOICE_HOLD_MS`、`BLUE_SEQ.voiceDelayMs` 或 `BLUE_SEQ.handGraceMs`
