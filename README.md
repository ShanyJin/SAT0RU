## 语言、推荐环境与加载

**中英双语**：欢迎页右上角与左侧栏设置里各有一组语言按钮（中文 / English），默认中文，选择写入 `localStorage['sat0ru.language']` 并在下次载入时生效。只有界面文案会切换；**技法名、顶栏状态、术式字幕始终使用繁体中文原名**（術式順転「蒼」/ 術式反転「赫」/ 虚式「茈」/ 領域展開「無量空処」）。英文文案在 `index.html` 的早期 classic 脚本里（`SAT0RU_I18N`），先于 three.js 模块执行，避免英文用户看到一闪而过的中文。

**推荐环境**（欢迎页第一张卡片同款）：

- Chrome / Edge 最新版，桌面端体验最佳
- Firefox 最新版可用
- Safari 17+ 可用；部分 iPhone / iPad 性能较弱
- 需要 HTTPS 或 localhost、摄像头权限，以及 WebGL 与 WebAssembly

**性能提醒**：开启浏览器硬件加速；关闭其他占用显卡的标签页或程序；在光线充足、背景清晰的环境中游玩；低端设备或软件渲染可能只有 1–3 fps，属正常现象，桌面 Chrome / Edge 最佳。

**加载优化**：

- 9 条语音全部 `preload="none"`；首次手势只静音预热短语音（iOS / Safari 需逐条在同一个手势内预热，会预热全部 9 条），长语音（`void-long`、`purple-clasp`）在教程关闭后空闲预取，真正需要时才加载
- 四式教程图改为 WebP（900px 长边，四张共约 376 KB），首次进入只为当前页设置 `src`，其余延后
- MediaPipe 的三条 classic 脚本不再放在 `<head>`：第一次点「启动」才注入，教程关闭后空闲 `<link rel=prefetch>`；摄像头 wasm / 模型仍只在启动后下载
- 渲染循环在标签页隐藏时暂停，可见时恢复；WebGL 上下文以 `powerPreference: 'high-performance'` 创建
- `tools/serve.py` 对 HTML / JS / wasm / data 等做 gzip（`index.html` 约 85 KB，three.js 约 258 KB）并在内存缓存压缩结果；`/vendor/`、`/assets/`、`/audio/` 返回一年 immutable 缓存，其余 `no-cache`

## 相比原版改了什么

### 1. 识别引擎重写（解决「手势不灵」的根因）

原版是单帧硬判断：每一帧按 y 坐标猜手指伸没伸，猜错一次特效就跳一次。最终版改为 **分数制 + EMA 平滑**（PR #6 的思路，重写实现）：

- 每个手势每帧输出 0~1 分数，EMA 平滑（α=0.20）
- 进入阈值 0.75 / 退出阈值 0.50，防抖
- 切换技法需领先当前技法 0.12 且持续 300ms 以上
- 单帧抖动不再跳变，双手中优先级排定（双 fists > 捏合+平掌 > … > 单手中最高分）

手势规则本身也收紧了（吸收 PR #10）：四指「并拢/张开」按食指-中指指尖距离区分（<0.05 / >0.10），捏合会抑制其他手势，拇指外张、双指夹角都参与判定。阈值集中在 `index.html` 的 `computeHandScores()`，不合手型可直接微调。

### 2. 只保留本作技法（其余上游技法已删）

上游合并版曾有 15 个技法；现在按主人要求全部删除，只留 **苍 / 赫 / 無量空処**（外加茈按钮模式、双手契印与 flick 尾巴）。
`?mode=all`、T 轮换、独立开场页入口、音乐、按键表、纯净模式都已移除；界面、技法名与 About 全部中文化。

### 3. 五条悟模式（当前默认）· 启用「苍」「赫」「無量空処」，茈有按钮模式与双手契印

「苍」是**持掌式**：**四指完全伸直**的张开手掌对着镜头**保持 2 秒**（弯着手指的手不算张开）→ **构筑**（手心先聚成小粒子球，随后展开成一大片呼吸浮动、飘散感明显的蓝色粒子状态，直径约 15~25cm，跟着手走）→ **释放**（持续前推 / **握拳** / **快速甩出** / 合掌 / 手出画面 / 丢失追踪 → 蓝色大爆炸）。构建期间慢速移动、旋转都不会打断；**构筑成型再满 2 秒才播苍的语音**（`audio/blue.mp3`，每次构筑一次；提前释放/取消不播）。**赫**有两种手势：单手食指向上指，或食指+中指并拢、拇指外张（枪形）——**进入瞬间是「激发」而不是淡入**：指尖枪口一闪，沿手指方向（手腕→指尖）**射出一道细长的红色枪矛**（高亮弹头 + 拖尾 + 前向冲击锥），红场同时压缩回弹并向后坐——是**向前打出去**，不是炸开；随后一颗**小红色球**（半径约 5、缓慢自旋 + 呼吸胀缩，外圈只有少量火星，共 1500 颗）悬在手指所指方向外、跟手移动，指住即持续存在——共享的 2 万颗大场在赫期间全程熄灯，帧率优先；**收手是原地「燃尽」**：红球停在原地缩小淡出、余烬下落消散，与激发完全两套动画；**松手后不会回中**——打到哪里就停在哪里；两种手势互换不断档；**任一赫手势保持 1 秒会随机播放一段赫的语音**（`audio/he-1|2.mp3`，每次保持播一次）；苍构筑/释放期间赫不触发，赫形态出现的帧也会清零苍的时序检测（快速比枪形不会误触）。**任何术式触发后 2 秒冷却**，防止前甩后手回收时的回摆连锁触发下一个术式。**虚式「茈」**有两种用法，**都只在右上角「茈」开关打开时成立**（开启后苍/赫暂停）：枪指式——枪形/捏合/拇指内扣**稳定保持约 0.25 秒**才蓄势紫色小球（闪一下的手势不算），再前推或「拇指内扣后快速向外弹开」发射到屏幕正中心爆开（**发射瞬间播茈的短语音** `audio/purple-short.mp3`），再点关闭恢复；以及**双手契印**：一只手张开、**四指全部朝上**、拇指内扣，另一只手扣住它（MediaPipe 经常只识别到张开的那只手，**单手也认**，但要多保持一会儿）——扣住就发动，是一段约 **23 秒**的长动画：先是**右侧蓝色蒼球**从中球膨胀到**半个屏幕大**（1.5 秒，球身静止、只有环带粒子在绕），**1.5 秒后左侧红色赫球**再用 2.5 秒长到与它对称；**发动 0.5 秒后**自动播契印语音；随后两球用 **3 秒**慢慢靠拢、压缩重叠，接着展开 **6 秒**的**紫色星系漩涡**（三臂星核差速旋转 + 三道倾斜陀螺环进动 + 每 1.4 秒一圈冲击波）、**7 秒**的相撞回弹，第 **20 秒**炸成紫色大爆炸，**23 秒**收尾——21.9 秒的语音在 22.4 秒结束，**语音先结束、动画后结束**。扣合期间模型掉成单手时，剩下的张开手仍算契印姿势，已累计的帧照常发动。契印必须打开「茈」开关；無量空処始终单手，四指朝上的契印姿势与领域手型不会互相误开。**領域展開「無量空処」**按参考视频：**单手**食指+中指并拢/交叉、拇指内扣（拇指外张的枪形仍是赫；领域只有单手，双手扣合才是茈的契印），展开白环 + 蓝色星云场，保持手势维持、松手退场；**比出满 1 秒播单人版语音**（`audio/void.mp3`）；**定格超过 3 秒**会自动播放旧 PR #7 的开场动画（已去掉标题与「进入」按钮），结尾从流星宇宙换成本作自己的白环粒子场——**环出现后黑幕再保持 10 秒**，随后黑幕淡出、背景透明而环还在，最后环淡出收场（一次保持只播一次，松手再结印可重播）。左侧栏设置里的**「长时间无量空处」**开关打开后，無量空処改成**保持 1 秒**：立刻展开领域并**立即播放 31 秒长语音**（`audio/void-long.mp3`）；**在原地再保持 8 秒**才进入约 34 秒的超长版动画（黑幕淡入放慢到 1.5 秒），语音在等待期间继续播放，**语音先结束、动画后结束**。

**音频库**：左侧栏「模式与音频」菜单里有「音频 · Audio」区块，9 条本地语音各一行，点击播放/停止（同一时间只播一条）：苍、赫·一/二、無量空処·单人/长版、茈短语音、双手契印、**失败**、**校训**——后两条只手动点击、不接任何手势。全部本地文件；彩蛋未开启时零外网请求。

**语音开关**：设置里的「术式语音 · Voices」（V 键）是**所有手势触发语音的总闸**，默认开启——关掉后苍/赫/無量空処/茈/契印的语音全部静音，左侧栏音频库的手动点击不受影响（失败 / 校训这两条本来就只手动点）。

**引力 / 斥力与待机尘埃**：屏幕常驻一层 1200 颗的灰蓝**环境尘埃**（慢速漂浮，就是「待机粒子」）——苍是吸引：构筑时尘埃螺旋收拢到蓝球四周，绕球旋转、跟着手走，释放瞬间被炸散再漂回；赫是排斥：红球出现时以红点为圆心把尘埃排开成一圈净空，收手后尘埃缓缓漂回。所有形态过渡都用逐粒子阻尼（0.18~0.48s）衔接，不会瞬移。

**技法名**一律用原版：術式順転「蒼」、術式反転「赫」、虚式「茈」、領域展開「無量空処」（顶栏中央状态显示，白色大字）。

### 4. 界面：Win11 石墨 Acrylic + 摄像头合成

页面按 Win11 风格重做（石墨灰黑底、毛玻璃卡片、青蓝强调色；规范见 navi `skills/web-design.md`）。摄像头画面全屏铺底并镜像，粒子特效以 `mix-blend-mode: screen` 叠在画面上，术式像是直接在你所在的房间里展开。

顶栏是三段式：**左上角菜单按钮**开合左侧栏，旁边是 **「启动」摄像头按钮**（按追踪状态显示启动中 / 等待追踪 / 追踪中 / 追踪异常 / 启动失败）；**正中央**用大号白字显示当前技法原名（繁体，如「領域展開『無量空処』」），没有发动任何术式时**不显示任何文字**；**最右侧**是「茈」模式开关和一行提示（点击开启 / 已开启的虚式「茈」枪指模式）。左侧栏是一整块 Windows 11 风格的透明亚克力面板，顶部是三个**小菜单标签**：**模式与音频 / 指南 / 关于**（点击切换，H 键在指南与主菜单间切换）。「模式与音频」里是 Win11 式开关，顺序为 **调试 → 术式语音 → 长时间无量空处 → 自定义无量空处**（点击即切换；调试 / 术式语音 / 长时间无量空处 也对应 D/V/L，H 单独切指南标签）；打开「自定义无量空处」后会在下面展开 **版本 1 / 2 / 3**、说明箭头与版本 3 的链接输入；再往下是 **音频 · Audio** 区：9 条本地语音，一行一条、点击播放/停止；「指南」是手势指南；「关于」写明原作作者与鸣谢、改版作者、个人网站、改版仓库、原项目、两条彩蛋视频的 B 站链接、侵权联系邮箱、开源依赖、**构建版本**（`BUILD_TAG`，用于确认没有跑缓存旧版）和本地化说明。手部骨架只在 **D** 调试模式下绘制。

| 食指+中指并拢、拇指外张（枪形） | 赫：同上（参考视频「赫 1/2/4」的第二种手势，两者可互换不断档） |
| 任一赫手势保持 1 秒 | 赫语音：随机播放 `audio/he-1.mp3` 或 `audio/he-2.mp3`（每次保持一次） |

- **赫**：复用库里原有的食指规则（`handShape().indexUp` + 其余三指收拢）；第二种枪形为 `indexUp+middleUp+指距<0.065+拇指外张（`thumbGapRatio`>0.75）+无名小指收拢`。EMA 平滑保证手指姿态过渡不会误触；红色激活期间两种手势切换或短暂丢手（<350ms）由桥接逻辑保持不断档，避免冷却期断触。任一赫形态出现的帧都会把苍的时序清零（`redFormSeen`）——做枪形时「张开→收指→张开」的自然动作不会误武装苍。赫的持续场是独立的小红球网格（`RED_BALL`/`redBall`/`fillRedBallPositions`，1500 颗、半径 4.6），共享的 2 万颗大场在赫全程不渲染、不插值、不上传属性（性能优化）；红球以「指尖（枪形取食指+中指中点）+ 沿指方向约 9×指节长度（≈7cm）」为锚点做阻尼跟随（`redAnchor`/`redFollow`，110ms），**结束后不回中**，就停在打到的位置。进入即激发（`RED_CAST`/`startRedCast`）：沿「手腕→指尖」方向（`redAnchor.aimX/aimY`）射出 420ms 的红色枪矛 + 枪口闪光 + 前向冲击锥，红球回弹并后坐，严格单向、没有径向爆发；退出到中性才原地燃尽（`startRedBurn`，620ms 缩小淡出 + 下落余烬），切到别的技法不播燃尽。构筑或释放苍期间赫被屏蔽（`frameScores.red = 0`），两个术式不会互相打断
- **术式冷却**：任何术式触发（苍释放/赫展开/茈发射/無量空処展开）后 2 秒内不再触发任何术式（`TECH_COOLDOWN_MS`，D 面板 `cooldown` 可见）——解决「赫前甩后手回收时又触发苍」的连锁误触；已激活的赫不受影响，会正常持续

- **苍的构筑**：张开手掌对着镜头**保持 2 秒**（前 3 帧确认张开才开始计时；握拳/收手即清零，按手独立、单手双手都认）后**不立即绽放**——**手心**先聚起小球，约 2 秒内展开成一大片「粒子状态」（直径约 15~25cm，`growMs`）：亮核 + 三条不同倾角的粒子环带（其中一条反向旋转，弧段留空隙）+ 大范围飘散体积雾（±26% 半径浮动），整体还有双频呼吸式胀缩（±16%/+7%）——像被释放出来的游离状态而非实心球，共 4000 颗。整团带阻尼跟手移动（拖动时拖在手掌后、停下再追上），并随**手腕转动**加减旋转。慢速大范围拖动、转动腕子都不打断；双手做也只锚定先完成的那一只手。构筑成型后再满 2 秒播苍语音（`BLUE_SEQ.voiceDelayMs` 与 `BLUE_SEQ.holdMs` 相互独立；提前释放/取消不播）
- **环的收尾**：無量空処开场动画里白环出现后黑幕保持 10 秒，之后黑幕淡出、背景透明而环还在，环再单独淡出；长版在 1 秒触发时就起长语音，再等 8 秒进黑幕，黑幕淡入 1.5 秒、保持 24 秒，动画总长约 33.8 秒（从进黑幕算），仍然「语音先结束、动画后结束」
- **释放**：持续前推（掌尺寸连续增长 ≥3 个采样、≥110ms、累计 ≥24%、平均增速 ≥1.7/秒；中间任一采样不涨即断链）、**握拳**（连续 2 帧收拢，单帧抖动不算）、**快速甩出**（连续 2 帧手速 ≥1.4 屏宽/秒且累计位移 ≥0.08）、**双手合掌**（两掌贴近约 ≤0.13）、手移出画面、追踪丢失超过 1 秒 → 光球瞬间消失，**屏幕中央**绽放蓝色大爆炸；慢速移动、横向挥动、转腕都只跟手，不释放
- **触发锁**：苍释放后演出约 2.5 秒，随后再锁 2 秒；另叠加全局 2 秒冷却（任何术式触发后）——期间任何手势都不触发
- **待机尘埃**：没有术式激活时保留一层轻量环境尘埃（1200 颗，慢漂移）；20k 主粒子场仍然整个隐藏（不占 GPU），构筑时只有光球粒子群 + 被吸过来的尘埃在跑。苍的引力把尘埃吸到蓝球四周旋绕并跟手，赫的斥力在红球周围清出一圈净空——引/斥的就是这层尘埃
- **语音**：全部本地 `<audio>`，首次点击/按键静音预热解锁自动播放；同一时间只播一条（新语音会停掉上一条）；赫/無量空処是「保持 1 秒 → 播一次」，苍是「构筑成型后再过 2 秒 → 播一次」；松手/释放后重比可再触发；左侧音频库可手动播放任意一条（失败/校训只手动）。设置里的**「术式语音」开关是手势语音的总闸**（默认开）：关掉后苍/赫/無量空処/茈/契印全部静音，音频库手动点击不受影响
- 构筑另有 30 秒安全上限（防止追踪卡死导致永远挂在构筑态）；手别标签翻转时会按邻近位置重新捕获
- 张开/握拳按「指尖到手腕距离 vs 指节到手腕距离」判定（>1.12 张开、<0.92 握拳），不依赖手掌朝向
- D 调试面板会显示 `fps`、`charge`（含实时手速）、`blueStages`、`bluePulse`、`gestureLock`、`cooldown`——阈值集中在 `CHARGE`、`BLUE_SEQ`、`VOICE_HOLD_MS`、`VOID_CINEMA`、`VOID_CINEMA_LONG`、`TECH_COOLDOWN_MS` 和 `handShape()`

## 运行

- 项目根目录 `/home/lain/sat0ru`，常驻服务 `sat0ru.service`（systemd 用户级，只监听 `127.0.0.1:8787`）：
  ```
  systemctl --user status sat0ru      # 状态
  systemctl --user restart sat0ru     # 改了代码不用重启，刷新页面即可；服务挂了用这个
  ```
  手动起（临时调试）：
  ```
  cd /home/lain/sat0ru && python3 tools/serve.py . 8787
  ```
  打开 `http://127.0.0.1:8787`；外网访问走 SSH 隧道。
- 需要摄像头（**只有点顶部「启动」按钮后才会请求权限**）；浏览器只在 `localhost` / HTTPS 下允许取摄像头
- **手机/平板**：`serve.py` 只绑 `127.0.0.1`，推荐在主机上 `tailscale serve --bg 8787`，手机浏览器打开 `https://<机器名>.<tailnet>.ts.net`（需先在 Tailscale 管理台启用 HTTPS；只在 tailnet 内可见，不暴露公网）。手机窄屏会自动铺满教程/侧栏、启动后自动收起侧栏；顶部「启动」按钮从「等待追踪」变成「追踪中」才算模型真正出结果（首次要下载约 23MB 本地模型，稍等几秒）
- `tools/serve.py` 已配好 MIME（`.wasm` → `application/wasm`，`.data` / `.tflite` → `application/octet-stream`）并默认 gzip + 缓存头；换别的静态服务器也要保证这两条 MIME。gzip 压缩结果缓存在内存（上限 64 MB），`/vendor/`、`/assets/`、`/audio/` 为 immutable，HTML 为 `no-cache`，所以改了 `index.html` 刷新即生效
- 全部依赖已本地化在 `vendor/`（MediaPipe Hands、three.js、字体），**默认零外网请求**；唯一例外是手动开启并触发的「自定义无量空处」彩蛋（加载 B 站播放器；版本 3 用你保存的链接）

## 已知限制

- MediaPipe Hands 是 2D 关键点 + 逐帧检测，极端光照、逆光、手太远仍会丢手；后续若还灵，升级路径是 MediaPipe Tasks `HandLandmarker`（新模型、世界坐标、时序更稳）
- 粒子用 screen 混合叠在摄像头上：画面极亮（比如对着窗户）时粒子会偏淡，属于预期；降低曝光或调高 bloom 可缓解
- 未点顶部「启动」时不会请求摄像头，也不加载模型；打开启动后若无摄像头/拒绝授权，MediaPipe 会弹「Failed to acquire camera」，属正常
- 启动弹窗**每次刷新都会出现**（有意不写 localStorage，保证每次使用前都重新告知隐私与用法）；四式教程可点顶部标签快速跳读
- 彩蛋的 B 站播放器是跨域 iframe：`autoplay=1` 只是请求，首次访问/浏览器策略可能拦截自动播放，此时按顶部提示点一下播放器即可；从摄像头手势触发的全屏请求通常会被浏览器拒绝，但覆盖层本身已铺满视口。彩蛋需要联网，且只对短版动画生效；版本 3 的链接只存在本机 localStorage，不会上传。
- 「前甩」用 2D 手速和手掌尺寸增速做代理（没有深度）；「甩出」用逐帧手速 + 累计位移做代理：逆光或追踪严重抖动时仍可能误判，调 `CHARGE.speedThresh / growthThresh / lostMs` 改灵敏度，`CHARGE.flingMinSpeed / flingMinDisplacement / flingRunFrames` 改甩出灵敏度，`followTauMs / trailScale` 改拖拽跟手手感
- 若构筑粒子群看起来卡顿：按 D 看 `fps`，持续低于 ~30 多半是 GPU 吃紧（核显 / 浏览器退到软件渲染），关掉其他占 GPU 的标签页即可；渲染分辨率已封顶 1.5×DPR，主粒子场在待机/构筑时整个隐藏，待机只剩 1200 颗尘埃当底噪，开销很小
- 「run away」语音识别依赖 Web Speech API，走 Google 在线识别，国内网络可能不通；术式语音和左侧音频库都是本地 MP3，不受影响
- 1 秒语音判定用的是连续手型保持，手抖或短暂丢手（<500ms）会算同一次保持；苍语音在构筑后才计时，提前释放就听不到。想更稳可调 `VOICE_HOLD_MS`、`BLUE_SEQ.voiceDelayMs` 或 `BLUE_SEQ.handGraceMs`
