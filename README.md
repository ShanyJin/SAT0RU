# SAT0RU · Domain Expansion — 合并最终版

基于 [reinesana/SAT0RU](https://github.com/reinesana/SAT0RU) 的私人合并版：把仓库里 10 个未合并 PR 里有价值的部分全部手工并入了一个 `index.html`，另附 PR #7 的独立开场动画页。

> 仅个人拍摄/娱乐使用。原仓库未附 LICENSE，请勿公开分发。

**文档**：`AGENTS.md`（工作区入口/铁律）· `docs/ARCHITECTURE.md`（技术全貌/参数表）· `docs/TESTING.md`（回归+截图验收）· `docs/CHANGELOG.md`（十二次改造史）

## 相比原版改了什么

### 1. 识别引擎重写（解决「手势不灵」的根因）

原版是单帧硬判断：每一帧按 y 坐标猜手指伸没伸，猜错一次特效就跳一次。最终版改为 **分数制 + EMA 平滑**（PR #6 的思路，重写实现）：

- 每个手势每帧输出 0~1 分数，EMA 平滑（α=0.20）
- 进入阈值 0.75 / 退出阈值 0.50，防抖
- 切换技法需领先当前技法 0.12 且持续 300ms 以上
- 单帧抖动不再跳变，双手中优先级排定（双 fists > 捏合+平掌 > … > 单手中最高分）

手势规则本身也收紧了（吸收 PR #10）：四指「并拢/张开」按食指-中指指尖距离区分（<0.05 / >0.10），捏合会抑制其他手势，拇指外张、双指夹角都参与判定。阈值集中在 `index.html` 的 `computeHandScores()`，不合手型可直接微调。

### 2. 技法从 6 个扩到 15 个 + 语音

移植了 PR #2 / #3 / #9 / #13 的技法函数与配色、bloom 强度。

### 3. 五条悟模式（当前默认）· 启用「苍」「赫」「無量空処」，茈有按钮模式与双手契印

按主人上传的参考视频，「苍」做成可交互的两段式：手势完成 → **构筑**（手心先聚成小粒子球，随后展开成一大片呼吸浮动、飘散感明显的蓝色粒子状态，直径约 15~25cm，跟着手走）→ **释放**（前甩 / 手出画面 / 丢失追踪 → 蓝色大爆炸）。构建期间慢速移动、旋转都不会打断。**赫**有两种手势：单手食指向上指，或食指+中指并拢、拇指外张（枪形）——红色场的核心红点悬在手指所指方向外约 5~10cm、跟手移动，指住即持续展开、收手退场，两种手势互换不断档；苍构筑/释放期间赫不触发，赫形态出现的帧也会清零苍的时序检测（快速比枪形不会误触苍）。**任何术式触发后 2 秒冷却**，防止前甩后手回收时的回摆连锁触发下一个术式。**虚式「茈」**有两种用法：顶部正中的模式开关（开启后苍/赫暂停，枪形/捏合/拇指内扣蓄势紫色小球，前推或「拇指内扣后快速向外弹开」发射到屏幕正中心爆开，再点关闭恢复），以及**双手交叉扣合**（十指交扣、食指朝上、拇指内扣）——不需要点按钮，扣住就发动：左侧蓝色粒子球 + 右侧红色粒子球同时变大，向中心靠拢重叠，随后炸成紫色大爆炸；单手同形仍然是無量空処。**領域展開「無量空処」**按参考视频：食指+中指并拢/交叉、拇指内扣（拇指外张的枪形仍是赫），展开白环 + 蓝色星云场，保持手势维持、松手退场。其余备选技法暂时不接——需要时 T 键可预览，`?mode=all` 恢复全套。

**引力 / 斥力与待机尘埃**：屏幕常驻一层 1200 颗的灰蓝**环境尘埃**（慢速漂浮，就是「待机粒子」）——苍是吸引：构筑时尘埃螺旋收拢到蓝球四周，绕球旋转、跟着手走，释放瞬间被炸散再漂回；赫是排斥：红球出现时以红点为圆心把尘埃排开成一圈净空，收手后尘埃缓缓漂回。所有形态过渡都用逐粒子阻尼（0.18~0.48s）衔接，不会瞬移。

**技法名**一律用原版：術式順転「蒼」、術式反転「赫」、虚式「茈」、領域展開「伏魔御廚子 / 無量空処 / 嵌合暗翳庭 / 坐殺博徒 / 真贋相愛 / 誅伏賜死 / 時胞月宮殿 / 自閉円頓裹」、黒閃、無為転変、十劃呪法「比率」、八握剣異戒神将魔虚羅（顶栏 pill 显示）。

### 4. 界面：Win11 石墨 Acrylic + 摄像头合成

页面按 Win11 风格重做（石墨灰黑底、毛玻璃卡片、暖金强调色；规范见 navi `skills/web-design.md`）。摄像头画面全屏铺底并镜像，粒子特效以 `mix-blend-mode: screen` 叠在画面上，术式像是直接在你所在的房间里展开；顶栏显示当前技法，左侧是按键表与手势指南卡片。按 **C** 进入纯净模式隐藏全部 UI 方便录制；手部骨架只在 **D** 调试模式下绘制。

## 手势表（五条悟模式 · 当前启用苍 / 赫 / 無量空処 + 茈按钮模式与双手契印）

| 手势 | 流程 |
|---|---|
| 单手或双手：张开 → 握拳 → 再张开 | 构筑 → 跟手 → 甩手释放（苍1 / 苍2 统一为同一套逻辑） |
| 单手食指向上指，其余三指收拢 | 赫：红点悬在手指所指方向外 5~10cm 跟手移动，指住即持续、收手退场；苍构筑/释放期间不触发 |
| 食指+中指并拢、拇指外张（枪形） | 赫：同上（参考视频「赫 1/2/4」的第二种手势，两者可互换不断档） |
| 点顶部「茈」→ 枪形/捏合/拇指内扣蓄势 → 前推或拇指外弹 | 茈：紫色小球射向屏幕正中心爆开；松手取消，释放后 2 秒冷却 |
| 双手交叉扣合（十指交扣、食指朝上、拇指内扣） | 茈·双手契印：左蓝右红两颗粒子球长大 → 向中心靠拢重叠 → 紫色大爆炸；无需点按钮、单手无效 |
| 食指+中指并拢/交叉、拇指内扣 | 無量空処：白环 + 蓝色星云；拇指外张的枪形仍是赫，两者靠拇指内扣/外张区分 |

- **赫**：复用库里原有的食指规则（`handShape().indexUp` + 其余三指收拢）与 `getRed()` 粒子演出；第二种枪形为 `indexUp+middleUp+指距<0.065+拇指外张（`thumbGapRatio`>0.75）+无名小指收拢`。EMA 平滑保证手指姿态过渡不会误触；红色激活期间两种手势切换或短暂丢手（<350ms）由桥接逻辑保持不断档，避免冷却期断触。任一赫形态出现的帧都会把苍的 open>fist>open 时序清零（`redFormSeen`）——做枪形时「张开→收指→张开」的自然动作不会误武装苍的构筑。整个红色场以「指尖（枪形取食指+中指中点）+ 沿指方向约 9×指节长度（≈7cm）」为锚点做阻尼跟随（`redAnchor`/`redFollow`，110ms），收手后退回屏幕中央淡出。构筑或释放苍期间赫被屏蔽（`frameScores.red = 0`），两个术式不会互相打断
- **术式冷却**：任何术式触发（苍释放/赫展开/茈发射/無量空処展开）后 2 秒内不再触发任何术式（`TECH_COOLDOWN_MS`，D 面板 `cooldown` 可见）——解决「赫前甩后手回收时又触发苍」的连锁误触；已激活的赫不受影响，会正常持续

- **构筑**：时序手势（张开 ≥3 帧 → 握拳 ≥2 帧 → 张开 ≥3 帧，每段须在 1.2 秒内完成，按手独立、单手双手都认）完成后**不立即绽放**——**手心**先聚起小球，约 2 秒内展开成一大片「粒子状态」（直径约 15~25cm，`growMs`）：亮核 + 三条不同倾角的粒子环带（其中一条反向旋转，弧段留空隙）+ 大范围飘散体积雾（±26% 半径浮动），整体还有双频呼吸式胀缩（±16%/+7%）——像被释放出来的游离状态而非实心球，共 4000 颗。整团带阻尼跟手移动（拖动时拖在手掌后、停下再追上），并随**手腕转动**加减旋转。慢速大范围拖动、转动腕子都不打断；双手做也只锚定先完成的那一只手
- **释放**：持续前推（掌尺寸连续增长 ≥3 个采样、≥110ms、累计 ≥24%、平均增速 ≥1.7/秒；中间任一采样不涨即断链）、**双手合掌**（两掌贴近约 ≤0.13）、手移出画面、追踪丢失超过 1 秒 → 光球瞬间消失，**屏幕中央**绽放蓝色大爆炸；慢速移动、横向挥动、转腕都只跟手，不释放
- **触发锁**：苍释放后演出约 2.5 秒，随后再锁 2 秒；另叠加全局 2 秒冷却（任何术式触发后）——期间任何手势都不触发
- **待机尘埃**：没有术式激活时保留一层轻量环境尘埃（1200 颗，慢漂移）；20k 主粒子场仍然整个隐藏（不占 GPU），构筑时只有光球粒子群 + 被吸过来的尘埃在跑。苍的引力把尘埃吸到蓝球四周旋绕并跟手，赫的斥力在红球周围清出一圈净空——引/斥的就是这层尘埃
- 构筑另有 15 秒安全上限（防止追踪卡死导致永远挂在构筑态）；手别标签翻转时会按邻近位置重新捕获
- 张开/握拳按「指尖到手腕距离 vs 指节到手腕距离」判定（>1.12 张开、<0.92 握拳），不依赖手掌朝向
- 其余备选技法**暂时不接**（代码保留）：T 键可手动预览，「?mode=all」恢复全套
- D 调试面板会显示 `fps`、`charge`（含实时手速）、`blueStages`、`bluePulse`、`gestureLock`、`cooldown`——阈值集中在 `CHARGE`、`BLUE_SEQ`、`TECH_COOLDOWN_MS` 和 `handShape()`

## 运行

- 项目根目录 `/home/lain/sat0ru`，常驻服务 `sat0ru.service`（systemd 用户级，只监听 `127.0.0.1:8787`）：
  ```
  systemctl --user status sat0ru      # 状态
  systemctl --user restart sat0ru     # 改了代码不用重启，刷新页面即可；服务挂了用这个
  ```
  手动起（临时调试）：
  ```
  cd /home/lain/sat0ru && python3 tools/serve.py . 8787
  ```
  打开 `http://127.0.0.1:8787`；外网访问走 SSH 隧道。
- 需要摄像头；浏览器只在 `localhost` / HTTPS 下允许取摄像头
- `tools/serve.py` 已配好 MIME（`.wasm` → `application/wasm`，`.data` / `.tflite` → `application/octet-stream`），换别的静态服务器也要保证这两条
- 全部依赖已本地化在 `vendor/`（MediaPipe Hands、three.js、字体），**零外网请求**

## 已知限制

- MediaPipe Hands 是 2D 关键点 + 逐帧检测，极端光照、逆光、手太远仍会丢手；后续若还灵，升级路径是 MediaPipe Tasks `HandLandmarker`（新模型、世界坐标、时序更稳）
- 粒子用 screen 混合叠在摄像头上：画面极亮（比如对着窗户）时粒子会偏淡，属于预期；降低曝光或调高 bloom 可缓解
- 无摄像头/拒绝授权时 MediaPipe 会弹「Failed to acquire camera」，正常
- 「前甩」用 2D 手速和手掌尺寸增速做代理（没有深度）：逆光或追踪严重抖动时仍可能误判，调 `CHARGE.speedThresh / growthThresh / lostMs` 改灵敏度，`followTauMs / trailScale` 改拖拽跟手手感
- 若构筑粒子群看起来卡顿：按 D 看 `fps`，持续低于 ~30 多半是 GPU 吃紧（核显 / 浏览器退到软件渲染），关掉其他占 GPU 的标签页即可；渲染分辨率已封顶 1.5×DPR，主粒子场在待机/构筑时整个隐藏，待机只剩 1200 颗尘埃当底噪，开销很小
- 语音依赖 Web Speech API，走 Google 在线识别，国内网络可能不通
